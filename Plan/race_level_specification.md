# レースレベルおよび実走スコア 仕様設計書

本書は、Ugaura（宇賀浦式 AI競馬予測システム）におけるレースレベル指標（Pre-Score / Post-Score / Current-Score）および出馬表での実走スコアの理論的背景、数理モデル、クラス基準点、ランク判定基準、およびUI表現仕様をまとめた公式ドキュメントです。

---

# 1. 概要と開発目的

### 1-1. 開発の背景
従来の競馬分析におけるレースレベル判定は、勝ち時計の速さや上がりタイムのみに依存することが多く、馬場状態や展開（超スローペース・ハイペース）による歪みを排除できませんでした。
また、出走馬が次走以降にどれだけ勝ち上がったか（次走成績）を手動で追跡する手法も広く使われていますが、主観的であり、レース前の客観的特徴量として活用することが困難でした。

### 1-2. 本モジュールの目的
1. レース前水準（Pre-Score）: 当該レース出走各馬の過去走実績から、出走メンバーの事前実力水準を客観数値化し、機械学習モデルの相手関係特徴量として利用可能にする。
2. 事後確定水準（Post-Score）: レース出走各馬の次走〜3走後までの実績（勝率・連対率・好走タイム差）をベイズ平滑化を用いて集計し、当該レースの真のハイレベル度を客観判定する。
3. 実走スコア（perf_score）: レース全体のレベルに対し、1着〜5着馬の平均タイムとのタイム差（上位5頭平均差）を加算・減算し、そのレースで各馬が発揮した実質的な能力値を単一の数値として可視化する。

# 3. レースレベル算出アルゴリズム

モジュール: calc_race_level.py（DuckDBによる一括高速集計）
格納先テーブル: SQLite `race_level`

### 3-1. レース前水準（Pre-Score）
出走各馬の前走着順、前走タイム差、および前走クラスとの格差から各馬の「前走スコア（horse_pre_score）」を算出します。
初出走馬や長期休養明け馬は中立値（2.5点）とします。

1. 現級・格上からの出走（同クラス実績・降級）:
   - 前走1着: 4.5点、2着: 3.5点、3着: 2.5点、4〜5着: 1.5点、6〜9着: 0.5点、10着以下: 0.0点
2. 下位クラスからの昇級初戦（格上挑戦）:
   - 前走勝ち上がり馬は標準（2.5点）スタート（前走勝利が過剰に跳ね上がるインフレを防止）。
   - 格上挑戦2着: 1.5点、3着: 1.0点、4着以下: 0.2点
3. タイム差加算:
   - 前走タイム差 <= 0.2秒: +1.5点、<= 0.5秒: +0.8点、<= 1.0秒: +0.3点、>= 2.0秒: -1.0点
4. クラス格差補正:
   - 前走が格上クラスで好走（5着以内）: +1.0点、同クラス好走: +0.5点

レース前レベル計算式:
`pre_level_score = class_base_score + (出走各馬のhorse_pre_score平均 - 2.5) * 8.0`
（※0.0点〜100.0点にクリッピング）

### 3-2. 事後確定水準（Post-Score）
当該レース終了後、出走各馬が次走〜3走後までの3走で獲得したポイントを集計します。

1. 各走の獲得ポイント（最大10点）:
   - 1着: 5.5点、2着: 3.8点、3着: 2.5点、4〜5着: 1.2点、6〜9着: 0.4点
   - タイム差好走加点: 0.2秒差以内 +1.5点、0.5秒差以内 +0.5点
   - 連勝ボーナス: 当該レース1着馬が次走も1着の場合 +2.0点
2. 走数重みづけ:
   - 次走（next1）: 重み 1.0
   - 2走後（next2）: 重み 0.8
   - 3走後（next3）: 重み 0.6
3. ベイズ平滑化（Prior Weighting）:
   小サンプル（まだ数頭しか次走を走っていない時期）のブレを抑えるため、事前期待値（prior_mean = 2.1点、prior_weight = 8.0走分）を混合。
   `actual_avg = (8.0 * 2.1 + 獲得ポイント総和) / (8.0 + 重み総和)`

事後確定レベル計算式:
`post_level_score = class_base_score + (actual_avg - 2.1) * 8.0`
（※0.0点〜100.0点にクリッピング）

### 3-3. 現在進行総合水準（Current-Score）
レース直後（次走出走ゼロ）から全頭次3走消化完了までの過渡期において、未消化走数の比率に応じて Pre-Score と Post-Score を線形補間します。

# 5. 実走スコア（perf_score）

### 5-1. 指数の定義
レースレベル（Post-Score）は「レース全体の強さ」を表しますが、レース内で各馬が発揮した実力は着差によって大きく異なります。
そこで、レースレベルに「1着〜5着馬の平均タイム（上位5頭平均）との差」を加算・減算した個体評価値を【実走スコア】と定義します。

### 5-2. 算出ロジック
1. 上位5頭平均差（top5_diff_sec）の算出:
   `top5_diff_sec = 自馬走破タイム - 1〜5着馬平均走破タイム`
   - 平均より速い場合: マイナス値（例: -0.6秒）
   - 平均より遅い場合: プラス値（例: +1.4秒）
2. タイム補正点の計算:
   `adj = - (top5_diff_sec * 8.0)`
   - 1秒差 ≒ 約8.0点換算（約1.3クラス分に相当）。
   - 不利や大差負けによる極端な減点を防ぐため、`adj` を `[-12.0点, +8.0点]` にクリッピング。
3. 最終スコア:
   `perf_score = ROUND(元レースレベル + adj, 1)`
   （※0.0点〜100.0点にクリッピング）
4. ランク判定:
   perf_score に第4章の8段階ランク定義を適用し、perf_rank（S〜D）を付与。

### 5-3. 効果
- ハイレベル戦の大敗馬が過大評価される罠を排除（例: B+ 55点のレースで1.4秒大敗 ➔ C+ 44点へ下落）。
- 低レベル戦の圧勝馬を正当に高評価（例: C+ 44点のレースで0.6秒差圧勝 ➔ B 48点へ昇格）。
- ハイレベルOP戦の僅差接戦馬を強力に浮き彫り（例: A+ 67点のレースで0.4秒差10着 ➔ A 63点として最高評価）。

# 6. 出馬表（UI）での表示仕様

画面モジュール: app_new_race_card.py（標準出馬表タブ）

### 6-1. セル構成（2段組み）
- 上段: `自馬着順(上位5頭平均差) [実走スコア ランク スコア]`
  - 例: `3着(+0.2) [B+ 55.2]`（鮮やかなブルーバッジ）
  - 例: `10着(+0.4) [A 63.3]`（アンバーバッジ。10着でも実質Aランクと一撃で判明）
  - 例: `11着(+1.4) [C+ 44.1]`（ティール青緑バッジ。前走B+戦でも大敗を反映して下落）
- 下段: `次3走: 1着数-2着数-3着数 / 走数 (勝馬次走着順)`
  - 例: `次3走: 2-1-0/4走 (勝①)`

### 6-2. ツールチップ（カーソルホバー）
バッジにマウスを乗せると、以下の詳細内訳がポップアップ表示されます。
`実走スコア: A 63.3 ｜ 元レースレベル: A+ 66.8 (タイム補正: -3.5点) ｜ レース前水準(Pre): A 62.0 ｜ 今回比: +1.5点 (同水準)`

### 6-3. 凡例表示
出馬表上部のインフォメーションボックスに以下の凡例を表示：
`【上段】自馬着順(上位5頭平均差) ｜ S〜D 実走スコア [ランク スコア] (※レースレベルに上位5頭平均差を加算・減算)`
`【下段】出走各馬の次3走成績 (1着数-2着数-3着数 / 走数) [勝馬次走]`

# 7. 過去出馬表の時系列スナップショット再現（Point-in-Time）

### 7-1. 目的と課題
過去のレースを検証・回顧する際、レース後に各馬が勝ち上がった最新の結果（未来情報）が反映されてしまうと、レース当時の実態と乖離し、正確なバックテストや予想検証が行えません。

### 7-2. 実装仕様（オンデマンド時系列計算）
出馬表ローダー（past_races_loader.py）において、対象レースの開催日（current_race_date）を基準とした時系列フィルタを適用：
1. 次走日付の厳密フィルタ: 各過去走の出走馬について、`next_race_date < current_race_date` を満たす次走成績のみを集計対象とし、未来の走は未出走（NULL）として除外。
2. 当時時点の総合レベル（Current-Score）の採用:
   - 直近走（1〜2ヶ月前）: 当時はまだ次走消化数が少ないため、Pre-Score（レース前水準）中心の安定したスコアを採用（未来の跳ね上がりを完全遮断）。
   - 昔の過去走（半年以上前）: 当時時点ですでに全頭消化済みのため、確定レベル（Post-Score）と一致。
3. 高速性の両立: DuckDBにより出馬表に表示される過去5走（最大90レース）のみを瞬時にオンデマンド計算（約0.8秒〜1.0秒）し、Streamlitキャッシュにより2回目以降は即時表示。
4. 効果: 過去のどの出馬表を開いても、「まさにその日その時に出馬表を見ていた状態」が寸分違わず100%忠実に再現されます。
