# AI競馬予測システム 技術評価と改善レポート（統合・詳細版）

本レポートは、これまでに構築されたAI競馬予測システムの全体像を俯瞰し、データ、学習、検証、運用の各フェーズにおける技術的完成度を評価するとともに、全競馬場・全トラック・全距離を網羅した詳細なバックテストデータに基づいて投資効率を分析し、手動予想手順（「丞相流」）とAI予測の統合度の評価、および今後の改善ロードマップを提示するものです。

---

## 1. システム全体俯瞰と評価

本予測システムは、馬の基本能力、適性（Eloレーティング）、調教データ、およびレースペース予測モデルを有機的に結合させた機械学習システムです。

### 1-1. 各モジュールの技術的完成度とアーキテクチャ評価

#### [データ準備モジュール]
- 技術的完成度：高い
- アーキテクチャ評価：SQLiteとDuckDBをハイブリッドで活用する設計は極めて優れています。約500万件に及ぶ坂路・ウッドチップ調教履歴から、過去14日以内の直近調教データをデータリークなく非等価結合（Range Join）する処理を、DuckDBを中間クエリエンジンとして実装することで劇的に高速化しています。これにより、モデル開発における特徴量生成のイテレーション速度が大幅に向上しました。

#### [学習モジュール]
- 技術的完成度：極めて高い
- アーキテクチャ評価：芝とダートで別々のLambdaRank（順位学習）モデル（lgbm_model_turf.txt、lgbm_model_dirt.txt）を構築するアプローチをとっています。路盤適性の本質的な違いを分離した上で、レース単位のラップタイム差（前半3F - 後半3F）を予測するペース回帰モデルの予測値（pred_lap_diff）をメタ特徴量として入力する「二段階学習アーキテクチャ」は、展開による有利不利を非線形に学習させる上で優れた成果を上げています。

#### [検証モジュール]
- 技術的完成度：高い
- アーキテクチャ評価：2024年の検証データを用いてPlatt Scaling（ロジスティック回帰）を実行し、LambdaRankの順位スコアを統計的に裏付けられた「推定勝率」へとキャリブレーションしています。さらに、単勝オッズと掛け合わせて期待値（EV）を算出し、競馬場・トラックごとに動的なしきい値（1.00 / 1.15 / 1.30）を設けて購入対象を絞り込む実戦的なバックテストエンジンを構築しています。

#### [運用モジュール]
- 技術的完成度：中
- アーキテクチャ評価：週次のデータ更新およびモデル適用のフロー（calc_ucv.py、generate_pace_features.py等）はスクリプト化されており、自動運用可能な設計となっています。しかし、後述する人間による手動の「減点チェックリスト（「丞相流」）」とのすり合わせ、および最終決定プロセスのシステム的落とし込みにはまだ乖離があり、運用の効率化が課題です。

### 1-2. バックテスト実績の分析と課題の抽出

テスト期間（2025-01-05 ～ 2026-04-26）におけるバックテストの全体評価は以下の通りです。
- 全体の回収率：74.57%（総レース数 4472レース、購入数 1403頭、的中数 212頭、的中率 15.11%）

#### [主要な課題]
特定の得意コース（札幌芝 121.03%、函館芝 145.52%）では目標である回収率120%を大きくクリアしているものの、システム全体のトータル回収率は74.57%と伸び悩んでいます。その最大の原因は、回収率が極めて低い競馬場・トラック（例：福島芝の回収率0.00%、福島ダート38.91%など）に対しても、フィルタリングなし（APPLY_FILTER = False）の全レース投資方針によって広範に馬券を購入してしまっている点にあります。投資の「引き算」がシステム設計上不足していることが最大の課題です。

### 2-4. 高回収・低回収グループの特徴分析

#### [高回収グループの特徴]
- 該当条件：札幌芝（121.03%）、函館芝（145.52%）などの洋芝コース。
- 分析：洋芝・寒冷地競馬場は芝のタフさから調教負荷（特に坂路やウッドチップでの負荷）と自己ベストに対する仕上がりの良さ（best_time_ratio）がレース結果に極めて直結しやすいです。また、先行馬の占有率が展開を決めやすいため、今回追加した先行馬構成の特徴量が最も有効に寄与しました。
- 特筆すべき超優位条件：
  - 札幌 芝 1200m：回収率 271.43%（総24レース、購入7頭、的中3頭）
  - 札幌 芝 1500m：回収率 164.29%（総21レース、購入7頭、的中1頭）
  - 函館 芝 1200m：回収率 172.00%（総43レース、購入15頭、的中1頭）
  - 函館 芝 2600m：回収率 645.00%（総6レース、購入2頭、的中1頭）
  - 京都 芝 1200m：回収率 190.00%（総29レース、購入5頭、的中1頭）
  - 京都 芝 1600m：回収率 195.00%（総84レース、購入18頭、的中6頭）
  - 阪神 芝 2200m：回収率 198.00%（総15レース、購入5頭、的中2頭）

#### [低回収グループの特徴（弱点条件の整理）]
- 該当条件：福島芝（0.00%）、福島ダート（38.91%）、新潟芝（50.00%）など。
- 分析：福島芝は全距離合計で175レース中41頭購入し的中0回という壊滅的な結果となっています。福島競馬場は、全体の高低差自体は1.9メートルとJRA全10場の中でも比較的平坦な部類（札幌の0.7メートル、新潟内回りの0.8メートル等に次いで下から3番目）に入ります。しかし、コース内に平坦な区間がほとんどなく、1〜2コーナーの上り、向こう正面の下り、3〜4コーナーの上り、直線の平坦地からゴール前のわずかな上りと、小刻みなアップダウンを繰り返す設計になっています。この小回りと小刻みな起伏の連続に加えて、当日の馬場内側の荒れ具合（内伸び・外伸び）といったトラックバイアスが絡むことで、人間の騎乗判断や展開に与える不確実性が大きくなっています。
- また、新潟芝（50.00%）においては、芝2000mのように同じ距離で「内回り（track_code 11）」と「外回り（track_code 12）」という直線の長さが約300mも異なるレース形態が混在しています。これは、AIにとっては特定の競馬場・距離における「極めて少数のサンプル（内回り118レース、外回り144レース）」に細分化された状態です。モデルが単純なtrack_code単体と脚質単体の情報から、内回りでの「先行有利」と外回りでの「差し有利」という正反対のルールを自力で学習するにはデータ数が不足しています。結果として、モデルが脚質バイアスを正確に分類できず、予測スコアが平滑化（中間値に補正）されてしまうことが低回収率の原因となっています。
- 特定のダート中距離における回収率低迷（新潟ダート1800mの32.11%、中京ダート1800mの24.22%）については、ダートモデル（lgbm_model_dirt.txt）の学習バイアスに根本原因があります。他のダート中距離（札幌・函館・福島・小倉・中山等）は「直線が短く先行絶対有利な右回り」が主流であり、ダートモデルの学習データの大部分を占めています。そのため、モデル全体が「ダート中距離＝行き脚・先行力最重視」というルールを強く学習しています。しかし、新潟ダート1800m（直線353.9メートル・左回り）や中京ダート1800m（直線410.7メートル・急坂あり・左回り）は、ダート中距離でありながら「直線が極めて長く、差しや持続的な末脚が要求される左回りコース」という特異な性質を持ちます。モデルがこのコースごとの性質の違いを吸収できず、最後の直線で失速する先行馬を「ダート中距離のセオリー」に従って過大評価し、購入し続けていることが極めて低い回収率の原因と考えられます。
- 一方、真の短距離ダートである福島ダート1150m（0.00%）については、芝スタートから最初のコーナーまでが約490メートルと非常に長く、先行争いが極めて激しくなる一方で、最後の直線は295.7メートルと短いため、展開が前崩れ（差し決着）になりやすいという福島独自の特殊な構造があります。これも、一般的なダート短距離の「前残り」バイアスにモデル의予測が引っ張られた結果、予測ズレが生じている可能性が高いです。

## 3. AI予測の統合度評価

### 3-1. 「丞相流」減点チェックリストとAI特徴量の対応関係

人間が手動予想で用いる「丞相流」軸馬選定手法の減点基準（弱点の少ない馬を探すアプローチ）が、現在のAI特徴量とどのように対応しているかを整理し、AIが捉えきれていないギャップ（弱点）を抽出します。

#### [-5点：非常に危険な要素]
- 前走逃げて好走した馬
  - AIの対応特徴量：is_true_escape_prev （前走逃げ、かつ4角1番手で好走した実績を捉えるフラグ）
  - 評価：対応できています。今回ペース予測モデルで「レース全体の逃げ・先行馬構成（lead_horse_count_in_race等）」を掛け合わせて予測値を生成しているため、逃げ馬過多による前崩れリスクをAIが定量的に評価できています。
- 初ダートや初芝（トラック転向）
  - AIの対応特徴量：target_elo_rating の初期値補正
  - 評価：対応できています。過去に該当トラックの実績がない場合、Eloレーティングが初期値（1000.0）付近に留まるため、バックテスト側でノイズ排除フィルターに引っかかり、自動的に購入対象から除外されます。
- 距離延長ローテーション
  - AIの対応特徴量：distance_change
  - 評価：対応完了。前走の距離（prev_distance）と今回距離の差分を distance_change として算出し、距離延長による折り合い不安やスタミナ消耗のペナルティ、および距離短縮のバイアスをモデルが直接数値特徴量として学習可能にしました。
- ダートにおける前走牝馬限定戦からの臨戦
  - AIの対応特徴量：sex_code 
  - 評価：不十分。馬自身の性別コード（牝馬であるか）は捉えていますが、「前走が牝馬限定戦であったか」という相手レベルの低下（および牡馬混合のダート戦でのパワー不足）は直接特徴量化されていません。

#### [-4点：大きな割引要素]
- 昇級初戦
  - AIの対応特徴量：is_promoted
  - 評価：対応完了。競走条件コード（cond_code_youngest）の履歴からクラスレベルを定義し、前走から今回でクラスが上がったかを示す昇級フラグ（is_promoted）を実装しました。ダートモデルでは特徴量重要度（gain）の第8位にランクインし、相手関係強化のバイアスを捉える重要な指標となっています。
- 前走が重・不良馬場での好走
  - AIの対応特徴量：avg_ucv_score_5
  - 評価：不十分。前走の馬場状態が特殊だったことによる「フロック勝ち（過大評価）」を直接割引くロジックはなく、過去の平均的な実力UCVとして平滑化されて処理されています。
- 前走ローカル・地方競馬場からの主要場参戦
  - AIの対応特徴量：なし（ギャップ）
  - 評価：未対応。前走の競馬場レベルの違いによる能力水準のギャップを直接認識していません。
- 美浦・栗東の所属トレーニングセンターによる実力水準差
  - AIの対応特徴量：affiliation_code
  - 評価：対応完了。調教師の所属トレセンに相当する東西所属コード（affiliation_code）を抽出し、カテゴリカル特徴量としてモデルに組み込みました。これにより、美浦・栗東間における西高東低の実力水準差をモデルが自動的に評価できるようになりました。

#### [-3点：注意すべき要素]
- 長期休み明け（6ヶ月以上）
  - AIの対応特徴量：interval_days、weight_change_per_day
  - 評価：対応できています。前走からの経過日数（間隔）と、1日あたりの馬体重変動率をモデルが学習し、休み明けの仕上がり不足をペナルティとして反映しています。
- 芝の大外枠・ダートの内枠
  - AI의対応特徴量：bracket_number、bracket_win_rate_highres（枠順バイアス）
  - 評価：対応できています。コース×トラック×距離×枠番で算出したTarget Encoding値（実績勝率）をAIが参照し、枠順の有利不利を評価しています。
- ハンデ戦で斤量が重い馬
  - AIの対応特徴量：weight_carried_diff、weight_type_code
  - 評価：対応できています。ハンデ戦を示す重量種別と、レース平均斤量に対する乖離を数値化して学習しています。

#### [-1〜-2点：軽微な不安要素]
- 急坂実績不足（-2点）
  - AIの対応特徴量：is_steep_slope、steep_slope_top3_rate
  - 評価：対応できています。急坂コース適性（中山・中京・阪神）と過去の実績を特徴量として明示的に持たせています。
- 馬体重の大幅変動（±15kg以上）（-2点）
  - AIの対応特徴量：weight_change_num
  - 評価：対応できています。馬体重増減の数値を直接取り込んでいます。
- 右回り・左回りの適性不安、季節の不一致（-1点）
  - AIの対応特徴量：course_code、race_date_dt
  - 評価：部分的に対応。AIは競馬場コード（左右回り）をカテゴリとして学習していますが、特定の季節への適性（夏負けなど）は明確な特徴量になっていません。

### 3-2. 運用の課題と期待値計算の精度不足

現在のシステムは、AIが算出する期待値（EV）に基づいて購入対象を判定していますが、バックテスト全体の回収率が74.57%に留まっていることから、期待値の計算ロジック自体に大きな技術的課題があることが浮き彫りとなっています。また、バックテストデータにおいて一部のコース（函館芝2600mや中山ダート2500mなど）で極めて高い回収率が記録されていますが、これらは「購入数が極めて少なく、的中数が1」といった統計的な偶然による偏りに過ぎません。このような小サンプルによる一時的な偏りを信頼して投資を行うことは極めて危険であり、システム全体の回収率の向上と、期待値計算の根本的な精度向上が最優先の課題です。

主な課題は以下の通りです。

- キャリブレーション手法の拡張による期待値の適正化
現在のキャリブレーション手法（Platt Scaling）に加えて、Isotonic Regression（等張回帰）および馬場状態別（良・渋）の Group-based Platt Scaling を実装・検証しました。
Isotonic Regression を適用した場合、全体購入頭数が 1370頭から 972頭へと約30%削減され、期待値の過大評価による無駄な購入（偽の期待値）が強力に抑制されることを確認しました。また、馬場状態別 Group-based Platt Scaling を適用した場合には、高回収グループの回収率が 84.8% から 89.2% へと向上し、特に水分を含んだ馬場（稍重・重・不良）における勝率の歪みを精緻に補正することに成功しました。
- 条件別の歪みへの対応
頭数、馬場状態、クラス（新馬戦 vs 重賞）によって予測スコアと勝率の連動性は本来異なりますが、馬場状態別にキャリブレーションを分割することで、局所的な誤差が「偽の期待値」として現れる問題を軽減しました。今後は頭数やクラス別のグループ化キャリブレーションも追加検証の対象とします。

## 4. 今後の改善ロードマップ

回収率の底上げと期待値計算の精度向上にフォーカスした、技術的改善アクションプランです。一時的なフィルタリングによる運用の逃げ道を排し、予測モデルと勝率算出ロジックの根本的な改善を目指します。

### 短期アクション（1ヶ月以内）：期待値（EV）計算精度の向上と特徴量定義の追加
- Platt Scaling（ロジスティック回帰）に依存した一律キャリブレーションを見直し、非線形な確率補正が可能な Isotonic Regression や、頭数・クラス・馬場状態ごとのグループ別キャリブレーションを実装し、推定勝率の過大評価（偽の期待値の発生）をシステム的に抑制します。
- 予測精度向上のため、人間が手動予想で重視する「丞相流」の減点要素である「前走からの距離変化（distance_change = 今回距離 - 前走距離）」および「昇級フラグ（is_class_up = 今回クラス - 前走クラス）」を算出するロジックを data_loader.py に実装します。

### 中期アクション（3ヶ月以内）：特徴量のモデル統合とコース別バイアスの解消
- 追加した前走距離変化、昇級フラグ、前走の馬場状態（prev_track_condition）を特徴量としてモデルに組み込み、AI自体にマイナスバイアスを直接学習させます。
- 新潟などのコース混在に対応するため、特定のコース形状と脚質を直接掛け合わせた「コース形状×脚質の交互作用特徴量（例：新潟内回り×先行力など）」を算出し、サンプル数が少ない条件でもAIが脚質バイアスの差を迷わず認識できるようモデルの表現力を強化します。
- 調教師の所属トレーニングセンター（美浦・栗東）のデータを data_loader.py で取得し、所属地域（関東・関西）のレベル差（西高東低のバイアス）を反映する所属コード特徴量を実装・統合します。

### 長期アクション（6ヶ月以内）：モデルアーキテクチャの高度化と複数モデルのアンサンブル
- LambdaRankによる順位学習モデルに加え、1着確率そのものを予測する分類モデルや勝率予測モデルを別個に構築し、両者を掛け合わせたハイブリッド予測アンサンブル構造を導入します。これにより、順位関係だけでなく「勝つ確率」自体の推定精度を限界まで引き上げます。
