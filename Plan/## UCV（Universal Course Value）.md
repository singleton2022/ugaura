# UCV（Universal Course Value）算出仕様および運用方針

最終更新日: 2026年10月23日
仕様バージョン: 2.1（中央・ローカル標準クラス統一基準タイムおよびパーセンテージ偏差馬場差移行版）

---

## 1. 概要と基本コンセプト

UCV（Universal Course Value）は、異なる競馬場・トラック・距離・馬場状態・クラスのレース結果を同一の尺度でフラットに比較するための、走破タイムベースの客観的能力偏差値（Zスコア）です。

主観的なハンデや定性的な評価を一切排除し、客観的なデータ（走破タイム・良馬場統一基準タイム・当日の馬場差）のみから統計的に算出されます。

### バージョン2.1における根本改修の背景
v2.0では各コース・距離ごとに単一の基準タイムを策定しましたが、中央4場（東京・中山・京都・阪神）とローカル競馬場（小倉・函館・札幌・福島・新潟）の間で「レース番組のクラス構成比（ローカルは約80%が未勝利・1勝クラス、中央は上位クラスが約2倍）」に大きな格差が存在したため、ローカル場の基準タイムが下級条件の遅いタイムに引っ張られて甘くなり、ローカルのUCVが高騰する現象が発生していました。
さらに、重・不良馬場のダート高速化において、秒数の生値によるトリム平均や2歳新馬戦の混入、過剰な縮小推定により馬場差が過小評価される課題がありました。

v2.1では以下の2大改修を実施し、中央・ローカル間の構造的不均衡と馬場差の歪みを完全に解消しました。
1. 全場標準クラス（1勝クラス水準）への走破タイム標準化による統一基準タイムの策定
2. レース偏差のパーセンテージ（比率）換算トリム平均、2歳新馬戦の除外、コース基準タイム比例による馬場差算出

## 2. 基準タイム（base_time）の算出方法

過去の膨大なレースデータから、各コース・距離における標準的な良馬場走破タイムを算出・マスタ化（ucv_base_time）しています。

### 算出条件とデータ抽出ルール
- 対象データ: 2019年6月1日以降（JRA降級制度廃止後）の良馬場レース。
- グループ化キー（3項目に完全一本化）:
  - 競馬場コード (course_code : 01〜10)
  - トラックコード (track_code : 芝・ダート・内外回りを厳密に区別)
  - 距離 (distance)

### クラス標準化（1勝クラス水準への換算）
各レースの走破タイムを、全国共通の「クラス期待偏差率（芝・ダート別）」に基づき、全場共通の標準クラスである「1勝クラス水準」に換算します。
- 標準化走破タイム = 走破タイム / (1.0 + クラス期待偏差率)
- クラス期待偏差率（1勝クラス = 0.000）:
  - 芝: 新馬未勝利 +1.40%, 1勝 0.00%, 2勝 -0.37%, 3勝 -0.87%, OP重賞 -0.88%
  - ダート: 新馬未勝利 +1.76%, 1勝 0.00%, 2勝 -0.83%, 3勝 -1.49%, OP重賞 -2.23%
これにより、未勝利戦が多いローカル場でも基準タイムが甘くならず、中央主要場と完全に同水準の引き締まった基準タイムが策定されます。

### 統計処理とロバスト標準偏差ガード
- サンプル数 5件以上の場合:
  標準化走破タイム群から上下10%の外れ値を除外したトリム平均（trim_mean 0.10）を「統一基準タイム（base_time_seconds）」として採用します。
- サンプル数 5件未満の場合:
  単純平均を適用します。
- 標準偏差（std_dev）のロバストガード:
  標準偏差下限値 = max(0.9, distance × 0.0006)
  （例: 1200mなら最低0.90秒、1800mなら最低1.08秒、2400mなら最低1.44秒を保証）

## 3. 馬場差（track_bias）の算出方法

当日の天候や含水率、路盤状態によるタイムへの影響を、日次・競馬場・トラックカテゴリ（芝/ダート）単位で自動補正します。

### 算出ステップとアルゴリズム
1. レース偏差率（パーセンテージ）の算出:
   各レースの中央値走破タイム（race_median_time）と統一基準タイムの乖離率を算出し、当該レースのクラス期待偏差率を差し引いて純粋な馬場バイアス率を抽出します。
   レース偏差率 = (レース中央値 - 統一基準タイム) / 統一基準タイム - クラス期待偏差率

2. 2歳新馬戦の測定除外:
   能力や展開が未完成でタイムのバラつきが大きい2歳新馬戦（cond_code_youngest=701, race_type_code=11）は、馬場差の基準測定から除外します。

3. 20%トリム平均（Trimmed Mean 0.20）による展開ノイズ遮断:
   同日・同場・同トラックカテゴリで行われた全対象レースの偏差率群から、上下20%を除外したトリム平均を算出します。

4. 経験ベイズ縮小推定による平滑化:
   当日のレース数（N）と平滑化係数（α = 1.0）を用いて縮小後バイアス率を算出します。
   縮小後バイアス率 = (N × 20%トリム平均 + α × 0.0) / (N + α)

5. コース距離に比例した馬場補正秒数の算出:
   各レースの該当コース基準タイムに縮小後バイアス率を乗じて補正秒数を導出します。
   馬場差(track_bias_seconds) = 統一基準タイム × 縮小後バイアス率
   補正走破タイム(corrected_time) = 走破タイム - 馬場差
   （これにより、短距離でも長距離でも距離に応じた正確無比な補正秒数が自動的に差し引かれます）

## 4. UCVスコアの算出式と外れ値クリッピング

補正走破タイムと統一基準タイムの差を、該当コースのロバスト標準偏差で割ることで標準化Zスコアを算出します。

### 算出式
Raw Z = (統一基準タイム - 補正走破タイム) / ロバスト標準偏差

### 外れ値クリッピング（ロバスト制限）
極端な大逃げ・馬場激変・計測ノイズによる異常値を排除し、機械学習モデルの安定性と可読性を担保するため、Zスコアの上限・下限をクリッピングします。
UCV Score = max(min(Raw Z, 4.0), -4.0)

出馬表UI上では、一般的な偏差値スケール（平均50、標準偏差10）に変換して表示します。
UCV偏差値 = 50.0 + (UCV Score × 10.0)
（表示レンジ: 10.0 〜 90.0）

## 5. 超スローペース戦の評価方針（確定方針）

### ペース補正を行わない基本原則
超スローペース戦などで走破タイムが全体的に遅くなり、UCVスコアが低く算出される現象に対して、「タイム（UCV）に対する主観的・仮説的なペース補正（タイムの底上げ加算）は一切行わない」ことをプロジェクトの基本規約として維持します。

### 理由と多角的な評価設計
1. UCVの純粋性の保持:
   走破タイム指数の中に仮説的な補正を混ぜ込むと、客観性と再現性が損なわれるためです。
2. 独立した指標による補完:
   超スローペース戦での好走馬や末脚の性能は、独立した「上がり3F指数（UCV 3F）」や「展開予測モデル（pred_lap_diff）」、「先行力（Dash）」、「Eloレーティング」によって多角的に評価します。

## 6. UCV 3F（上がり3ハロン専用指数）の算出仕様

UCV 3F は、走破タイム全体の評価（UCV）とは独立して、各馬の「最後の直線での末脚・加速性能」を客観評価する上がり専用のZスコア指数です。

### 6-1. 上がり3F基準タイム（base_3f_time）
- グループ化キー: コースコード、トラックコード、距離
- クラス標準化:
  走破タイムと同様、全国共通の「上がり3Fクラス期待偏差率」を用いて全レースを1勝クラス水準に標準化した上で中央値を算出。
  （芝: 新馬未勝利 +1.67%, 1勝 0.00%, 2勝 -0.73%, 3勝 -1.02%, OP重賞 -0.78%）
  （ダート: 新馬未勝利 +2.43%, 1勝 0.00%, 2勝 -1.10%, 3勝 -1.74%, OP重賞 -2.61%）
- 統計処理:
  良馬場における標準化上がり3Fタイムの中央値（median）を採用。
  上がり3F標準偏差（base_3f_std）は0.4秒未満の場合にデフォルト値（0.8秒）を適用。

### 6-2. 上がり3F馬場差（track_bias_3f）
当日の馬場における上がりの要しやすさを補正します。
1. 各レースの上がり3F中央値と基準タイムの乖離率からクラス期待偏差率を差し引いて偏差率を算出。
2. 2歳新馬戦を除外し、20%トリム平均および縮小推定（α = 1.0）を用いて上がりバイアス率を導出。
3. コースの上がり3F基準タイムに乗じて上がり馬場差秒数（track_bias_3f_seconds）を算出。
補正上がり3Fタイム = 上がり3Fタイム - 上がり馬場差

### 6-3. UCV 3F スコア算出式
Raw Z_3f = (上がり3F基準タイム - 補正上がり3Fタイム) / 上がり3F標準偏差
UCV 3F Score = max(min(Raw Z_3f, 4.0), -4.0)
UCV 3F 偏差値 = 50.0 + (UCV 3F Score × 10.0)
